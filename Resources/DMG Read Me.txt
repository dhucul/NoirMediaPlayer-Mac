NOIR Media Player for macOS — Apple Silicon preview, build 5

Drag NOIR Media Player into Applications, then open it.
Requires an Apple Silicon Mac (M1 or later); the deployment target is macOS 13.

AVFoundation provides native playback. VLC and the Apple Silicon AACS runtime
are bundled for compatibility, DVD and Blu-ray playback. No separate VLC
installation is needed. Protected Blu-rays require suitable keys: open Settings
and choose Download AACS keys, or install a compatible KEYDB.cfg in the key
folder. Keys are not included in this installer. Library overrides require a
restart; installing or updating keys does not. Press Play to retry a failed source.

Use Eject Disc in NOIR or Command-E to release playback and eject the disc.
Disc menus accept mouse clicks, Option-arrow navigation and Return to activate.

Open media: Command-O. Open folder: Shift-Command-O.
Network stream: Command-L. Disc: Command-D. Eject: Command-E.
Space: play/pause. F: fullscreen. P: mini player. S: snapshot.
I: inspector. B: queue.

Build 5 fixes retry after AACS setup, partitioned-disc release, key-only AACS
configuration validation, and normal end-of-file handling when UI polling is
delayed. It retains build 4's Blu-ray runtime and disc-menu mouse support.
Regression tests use synthetic media and mock eject adapters. The prior build
was also checked with a physical Blu-ray; a broader drive/disc matrix and older
macOS versions still need testing. BD-J menus may require Java; BD+ and UHD
AACS 2.x protection are not provided by the bundled AACS runtime.

This preview is ad-hoc signed and is not Apple-notarized.
